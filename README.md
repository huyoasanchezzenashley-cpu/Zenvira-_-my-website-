# ZENVIRA — Jewelry Showcase Website

A fictional online jewelry showcase created for the HTML & CSS Creative Web Development activity.

## Website concept
**Online Product Showcase** — ZENVIRA presents an original collection of imagined jewelry concepts with product names, descriptions, sample prices, and a coordinated visual identity.

All product names, product concepts, and sample prices in this project are fictional and were created for this student project. They do not represent existing products or a real store.

## Technologies
- HTML5
- CSS3
- No JavaScript
- No JavaScript libraries or frameworks

- `index.html` — Home page, introduction, featured products, and navigation.
- `about.html` — Brand concept, story, and design values.
- `gallery.html` — Six fictional jewelry concepts with descriptions and illustrative prices.

## Preview locally
1. Download and extract the ZIP file.
2. Open the `ZENVIRA-jewelry-showcase` folder.
3. Double-click `index.html` to open the website in a browser.
4. Use the navigation links to visit the other pages.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `zenvira-jewelry-showcase`.
2. Upload the contents of this project folder. Make sure `index.html` is in the repository's root.
3. Open the repository's **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site. Open the URL shown in the Pages settings.

## Notes
- All navigation uses ordinary HTML links.
- The layout adapts to desktop, tablet, and mobile screen widths using CSS media queries.
- The jewelry artwork is drawn with CSS shapes and gradients, so no external product photographs are required.
- Google Fonts are imported for typography when an internet connection is available; fallback fonts are included.
